# Supplementary Code

This directory contains the software and simulation code accompanying the
manuscript.

- `R package TLDA/` contains version 0.2.0 of the `TLDA` R package, its source
  code, reference manual, and installation instructions.
- `simulation study for S1/` contains the code and summary results for
  reproducing Scenario 1 at three support-mismatch levels.

See the `Readme.md` file in each directory for installation, file
descriptions, and usage instructions.
